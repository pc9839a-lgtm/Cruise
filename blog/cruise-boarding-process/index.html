크루즈 탑승 절차｜체크인부터 승선까지 처음 가는 사람 가이드

처음 크루즈를 타면 공항처럼 복잡할 것 같지만 실제 순서는 단순합니다. 터미널 도착 → 캐리어 위탁 → 체크인 → 보안검색 → 승선 → 안전교육 흐름만 알면 됩니다.

승선 전에 준비할 것

  • 여권
  • 승선권 또는 선사 앱
  • 예약 영문명 확인
  • 터미널 주소
  • 지정 도착시간
  • 휴대가방과 위탁 캐리어 분리

1. 터미널 도착

출항시간만 보고 움직이지 말고 예약서나 앱에 표시된 도착시간을 기준으로 갑니다. 같은 항구에 여러 선박이 정박할 수 있으므로 선박명과 터미널을 같이 확인해야 합니다.

2. 큰 캐리어 위탁

큰 짐은 터미널에서 먼저 맡기는 경우가 많습니다. 여권, 약, 지갑, 휴대전화, 충전기는 맡기지 말고 직접 들고 타세요. 위탁 캐리어는 객실에 늦게 도착할 수 있습니다.

3. 체크인과 서류 확인

승선권, 여권, 예약정보를 확인합니다. 온라인 체크인을 끝냈더라도 실물 여권과 필요한 입국서류는 별도로 준비해야 합니다.

4. 보안검색

가방은 검색대를 통과합니다. 선사 반입규정에 맞지 않는 물건은 반입이 제한될 수 있으므로 멀티탭, 주류, 다리미 같은 품목은 출발 전에 확인하세요.

5. 승선카드 확인 후 배에 오르기

승선카드는 객실키이면서 선내 결제와 본인 확인에 사용됩니다. 선사에 따라 모바일 카드나 실물 카드 제공 방식이 다를 수 있습니다.

6. 객실보다 먼저 해야 할 것

↓ 식사·공연 예약 확인

↓ 객실 준비 여부 확인

↓ 캐리어 도착 확인

처음 타는 사람이 가장 많이 헷갈리는 것

  • 출항시간과 체크인 마감시간을 같은 것으로 생각함
  • 여권을 큰 캐리어에 넣음
  • 승선권을 인터넷이 있어야만 열 수 있게 둠
  • 터미널 주소를 정확히 확인하지 않음
  • 객실이 즉시 열릴 것이라고 생각함

승선 시간을 판단하는 실제 사례: 로얄캐리비안

같은 날 오후 5시에 배가 출발하더라도 터미널 도착 예약 시간과 최종 체크인 마감은 다릅니다. 로얄캐리비안은 앱에서 지정된 도착 시간에 맞춰 터미널에 올 것을 안내하며, 일반적으로 출항 예정 시각보다 적어도 90분 전에 체크인을 마쳐야 한다고 명시합니다. 항구별 운영 마감이 더 빠를 수 있으므로 선사 앱의 승선권과 출항 안내를 반드시 우선 확인해야 합니다.

확인 항목어디서 확인하나놓치면 생기는 문제
승선 날짜·출항항예약 확정서인접 도시의 다른 터미널로 이동
터미널 도착 슬롯선사 앱·모바일 승선권일찍 도착해도 바로 탑승 못 할 수 있음
최종 체크인 마감선사 승선 안내·항구 운영시간늦으면 탑승 거부 가능
여권·전자승선권예약 이메일·선사 앱현장 재확인·대기 증가

실전 확인 순서: 출항 7일 전 예약번호와 선박·출항항 확인 → 전날 앱에서 도착 슬롯과 승선권 저장 → 이동 당일 교통 지연 대비 → 출항 당일 터미널 직원에게 안내 받은 체크인 절차 수행. 도착 슬롯을 보지 않고 출항 시각만으로 이동 계획을 짜지 마세요.
