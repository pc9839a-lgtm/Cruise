크루즈 탑승 절차｜체크인부터 승선까지 처음 가는 사람 가이드

처음 크루즈를 타면 공항처럼 복잡할 것 같지만 실제 순서는 단순합니다. 터미널 도착 → 캐리어 위탁 → 체크인 → 보안검색 → 승선 → 안전교육 흐름만 알면 됩니다.

승선 전에 준비할 것

  • 여권
  • 승선권 또는 선사 앱
  • 예약 영문명 확인
  • 터미널 주소
  • 지정 도착시간
  • 휴대가방과 위탁 캐리어 분리

1. 터미널 도착

출항시간만 보고 움직이지 말고 예약서나 앱에 표시된 도착시간을 기준으로 갑니다. 같은 항구에 여러 선박이 정박할 수 있으므로 선박명과 터미널을 같이 확인해야 합니다.

2. 큰 캐리어 위탁

큰 짐은 터미널에서 먼저 맡기는 경우가 많습니다. 여권, 약, 지갑, 휴대전화, 충전기는 맡기지 말고 직접 들고 타세요. 위탁 캐리어는 객실에 늦게 도착할 수 있습니다.

3. 체크인과 서류 확인

승선권, 여권, 예약정보를 확인합니다. 온라인 체크인을 끝냈더라도 실물 여권과 필요한 입국서류는 별도로 준비해야 합니다.

4. 보안검색

가방은 검색대를 통과합니다. 선사 반입규정에 맞지 않는 물건은 반입이 제한될 수 있으므로 멀티탭, 주류, 다리미 같은 품목은 출발 전에 확인하세요.

5. 승선카드 확인 후 배에 오르기

승선카드는 객실키이면서 선내 결제와 본인 확인에 사용됩니다. 선사에 따라 모바일 카드나 실물 카드 제공 방식이 다를 수 있습니다.

6. 객실보다 먼저 해야 할 것

선사 앱 확인

↓ 안전교육 또는 머스터 스테이션 확인

↓ 식사·공연 예약 확인

↓ 객실 준비 여부 확인

↓ 캐리어 도착 확인

처음 타는 사람이 가장 많이 헷갈리는 것

  • 출항시간과 체크인 마감시간을 같은 것으로 생각함
  • 여권을 큰 캐리어에 넣음
  • 승선권을 인터넷이 있어야만 열 수 있게 둠
  • 터미널 주소를 정확히 확인하지 않음
  • 객실이 즉시 열릴 것이라고 생각함
